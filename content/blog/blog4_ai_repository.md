## Projects

### 1. Library Management System
**Course:** Advanced Object-Oriented Programming

Designed and implemented a desktop-based Library Management System supporting realistic library operations for staff and members. The project applied advanced object-oriented design principles including encapsulation, composition, polymorphism, layered architecture, and defensive programming.

---

### 2. Handwritten Digit Recognition Using Neural Networks
**Course:** Neural Networks and Deep Learning

Developed and evaluated multiple neural network architectures for MNIST digit classification. Experiments included Multilayer Perceptrons (MLP) trained using SGD, RMSprop, and Adam optimizers, as well as regularization techniques such as dropout. A Convolutional Neural Network (CNN) extension achieved approximately 99% classification accuracy.

---

### 3. Vehicle Recognition for Road Safety Monitoring
**Course:** Neural Networks and Deep Learning

Built and compared CNN and LSTM-based deep learning models for vehicle and non-vehicle image classification. Using approximately 17,760 labelled images, the CNN model achieved around 99.7% test accuracy and significantly outperformed the sequence-based LSTM approach.

---

### 4. Deep Learning-Based Sentiment Analysis
**Course:** Applied Natural Language Processing

Implemented and compared SimpleRNN, GRU, and LSTM architectures for Twitter airline sentiment classification. The project explored word embeddings, sequence modelling, regularization strategies, overfitting analysis, and performance trade-offs across recurrent neural network architectures.

---

### 5. Deep Learning-Based Question Answering System
**Course:** Applied Natural Language Processing

Developed an extractive Question Answering system using GloVe embeddings, Bidirectional LSTM encoders, and attention mechanisms. The model was trained on the Stanford Question Answering Dataset (SQuAD v2.0) and performed answer span prediction as well as answerability classification.

---

### 6. Cardiovascular Disease Prediction
**Course:** Data Warehousing and Mining

Conducted a comprehensive machine learning analysis of a cardiovascular disease dataset containing over 66,000 patient records. Logistic Regression, Decision Trees, Random Forests, and Support Vector Machines were implemented and compared. Feature importance analysis identified blood pressure, age, cholesterol, and BMI as the most influential predictors.
